# Mojito analysis

Code for matching `fastlisaresponse` to the Mojito simulation, and for
parameter estimation on the Mojito EMRI sources with the fast template model.

## Repository content

### Analysis

- `FLR_sim_vsc.ipynb` — the main notebook: compares the Mojito L1 TDI data to
  the `fastlisaresponse` template, in the time and frequency domain, for each
  source. This should be understandable for other people to go through.
- `PE_validation.py` — PE run that validates the Mojito EMRIs against the fast
  template. One source per invocation:
  ```console
  python PE_validation.py --source=0 --cluster=vsc
  ```
- `analyse_samples.ipynb` — post-processing of the Eryn chains produced by
  `PE_validation.py`.
- `timing.ipynb` — the Mojito timing conventions, and the derivation of the
  orbits file used by the analysis.

### Inputs

- `esa-trailing-orbits-mojito_validation_test_2.h5` — orbits file, generated by
  `timing.ipynb`.
- `parameters_mojito_validation_test_2.yaml` — parameters of the validation run.
- `mojito_catalog_standardized_processed.hdf5` — source catalogue.

### Results

- `output/results.md` — quantitative results for each source (SNRs, mismatches).
- `output/source_<i>/` — time- and frequency-domain response and residual
  figures, corner plots, and the Eryn backend (`PE_run_source_<i>.h5`, not
  versioned) for source `<i>`.

### Environment

- `lisa_inference.def` — the Apptainer definition file for the container with
  all dependencies. Pins the commits of GPUBackendTools, LISAanalysistools and
  fastlisaresponse that the analysis was run against.
- `kernel.json` — Jupyter kernel spec that runs the notebooks inside the
  container.
- `test.py` — checks that the GPU backends are found by FEW.
- `scripts/` — Slurm submission scripts for the PE runs.

### Other

- `legacy/` — superseded scripts, notebooks and container definitions, kept for
  reference. See `legacy/README.md`.

## Reproduction

`lisa_inference.def` contains everything needed: pip-installable packages and
source installations. To build the container, first make sure that apptainer can
talk to the ESA Gitlab registry:

```console
apptainer registry login -u <username> docker://gitlab.esa.int:4567
```

Authenticate here with a personal access token.

Optional: point the apptainer build at large storage:

```console
$ export APPTAINER_CACHEDIR=<path/to/large/storage>/.apptainer_cache
$ export APPTAINER_TMPDIR=<path/to/large/storage>/apptainer_tmp
```

Build the `.sif` container image:

```console
apptainer build --fakeroot lisa_inference.sif lisa_inference.def
```

To check that the GPU is found correctly by FEW:

```console
$ apptainer exec --nv lisa_inference.sif python3 test.py
```

To run the PE:

```console
$ apptainer exec --nv lisa_inference.sif python3 PE_validation.py --source=0 --cluster=vsc
```

`PE_validation.py` reads the LISA consortium credentials from a `.env` file in
the repository root:

```
LISA_CONSORTIUM_NAME=<username>
LISA_CONSORTIUM_KEY=<token>
```
